# Kolo'e Koa Dojo Kenpo

Website oficial do Kolo'e Koa Dojo Kenpo.

Projeto desenvolvido para apresentar o dojo, a sua filosofia, linhagem,
atividades, horários, galeria, vídeos e informações de contacto,
proporcionando uma presença digital moderna e acessível.

---

## 🥋 Sobre o projeto

O Kolo'e Koa Dojo Kenpo é uma escola dedicada à prática do Kenpo,
defesa pessoal e desenvolvimento físico, mental e espiritual.

Este website foi desenvolvido com o objetivo de:

- Apresentar o Kolo'e Koa Dojo Kenpo;
- Dar a conhecer o Kenpo e a filosofia da escola;
- Apresentar a linhagem e a história do dojo;
- Divulgar horários e informações dos treinos;
- Apresentar fotografias e vídeos;
- Facilitar o contacto com o dojo;
- Disponibilizar a localização através do Google Maps;
- Criar futuramente uma área de administração para gestão de conteúdos.

## 🚀 Tecnologias

O projeto foi desenvolvido utilizando:

- **Vue 3** — framework JavaScript para construção da interface;
- **Vite** — ferramenta de desenvolvimento e build;
- **Tailwind CSS** — framework CSS para construção da interface;
- **JavaScript** — linguagem principal do projeto;
- **Git** — controlo de versões;
- **GitHub** — alojamento do código-fonte.

### Planeado para fases futuras

- **Supabase** — autenticação, base de dados e armazenamento;
- **Supabase Storage** — armazenamento de fotografias e vídeos;
- **Vercel** — deployment e alojamento do website;
- **Google Maps** — localização do dojo;
- Área de administração;
- Gestão dinâmica de fotografias e vídeos;
- Gestão de horários;
- Sistema de mensagens/contactos.
